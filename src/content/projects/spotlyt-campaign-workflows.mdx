I wanted to know why checkout and content review kept diverging between pages. Campaign state rules were copy-pasted and easy to get wrong.

I contributed small rule modules on the Spotlyt customer app (Next.js 16, Server Actions) for post-checkout redirects, profile validation, payment tab filters and related slices. On the Delivery workspace (React, Vite) I contributed content-review eligibility, delivery-manager approvals, profile sync with polling, and shared UI helpers. These are shared codebases with other authors.

I would add a one-page state diagram for campaign and content status before the next redirect change, so new contributors see the same picture I had in my head.

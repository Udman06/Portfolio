I wanted to know whether we could replace the legacy admin without breaking bookmarks or daily ops work. Operators still needed auth, discovery, org wallets, and payouts while dozens of old URLs existed.

I built from setup with a route-parity registry first, then shipped modules in priority order with one API client in front of the legacy backend. Stack: React 19, TanStack Start, Router and Query, Tailwind CSS 4, shadcn/ui. Auth includes roles; discovery, organisations, payouts and KYC views are in place while many legacy routes stay placeholders.

Next time I would split the helper surface earlier—even with a registry, some shared table patterns could move out before the module count grows.

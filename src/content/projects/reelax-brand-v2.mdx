I wanted to know why connect worked in mocks but failed on staging. Gmail and WhatsApp did not return the same kind of payload.

I contributed Gmail OAuth and a 161-line WhatsApp Embedded Signup module, with DTO mapping and tests on Next.js 16 and Zod. Local dev runs over HTTPS for Meta's SDK. Chat sync and template forms are in progress and are not released.

I would write HTTPS, script and popup requirements in project docs before the first UI mock, not after the first failed login.

I wanted to know if a video-heavy landing page could still score 95+ on Lighthouse and still convert visitors. Autoplay rules and many looping reels made that a real question.

I implemented the Figma section system in React 19 and Vite, kept one page-level playback manager for the hero, creator wall and demo modal, and lazy-loaded below-the-fold sections. Privacy and Terms sit on their own routes; the contact form validates name, email and optional 10-digit Indian mobile before the API call, with toast feedback. Environment-specific Open Graph metadata covers the OG image and hero media per deploy.

I would document autoplay and bandwidth limits in the repo README on day one so the next video section does not rediscover the same constraints.
